# Activity Boundaries

## Package authoring performed

Permitted activity is limited to UTF-8 documentation authoring, deterministic
archive construction, inventory generation, and checksum verification for
Sentinel review.

## Not performed and not authorized

- workspace creation or validation;
- capture extraction or payload copying;
- source or test authoring;
- imports, lint, compilation, coverage, tests, or project execution;
- research-data, credential, API, RPC, vendor, or network activity;
- project-artifact or empirical-result generation;
- Git write, commit, push, merge, ref update, or canonical repository change;
- failed-gate repair, reuse, reactivation, or false-clear representation;
- checkpoint acceptance or promotion;
- reliance on `MULTI_ROUND_ACTIVITY_LINEAGE_INCOMPLETE`;
- any downstream Candidate 04 stage.

The ZIP contains no executable script, source code, test code, binary payload,
or copy of the accepted capture archive.
